# 腎上腺類固醇：補充、抑制與受體阻斷：設計與來源對照

Block 2 基礎考試 3；1001 腎上腺類固醇，含本堂。講義＋1001淨化稿＋Katzung Ch39；課堂劑量僅為辨識用途

## 圖在做什麼

### 圖1 HPA 與 GR：補荷爾蒙也會關掉上游

先看 HPA 產生 cortisol，再看 cortisol 在細胞內作用；長期外給會降低自身供應。

來源：類固醇講義 PDF p.4、7–8、11；1001淨化稿 L21–27、55–87；Ch39

圖的界線：負回饋在文字呈現，未以普通箭頭混成促進路徑；GR 可活化或抑制不同基因，非所有效應皆靠 GRE 二聚體。 圖中ACTH琥珀框代表負回饋下調，不是藥物直接阻斷酵素。綠框表示外給藥支持GR下游。

### 圖2 合成阻斷：早段與末段的差別

上游阻斷影響多種荷爾蒙；11β-hydroxylase 阻斷可讓前驅物累積。

來源：類固醇講義 PDF p.3、25–27；Ch39

圖的界線：簡化管線刻意未畫 aldosterone 全支線；mid 框為多步而非單一化學反應。CYP21 缺陷 CAH：cortisol↓→ACTH↑→增生／雄性素偏流，見比較表。

### 圖3 MR 的入口保護與水鹽結果

MR 對 cortisol 也有親和力；11β-HSD2 把 cortisol 轉成 cortisone，保護 aldosterone 的選擇性。

來源：類固醇講義 PDF p.9、14–15、28；1001淨化稿 L95–125；Ch39

圖的界線：HSD2 不作用在 aldosterone 此線；cortisone 可在其他組織經 HSD1 再活化，不能稱永遠無效。Na+ 保留並非直接等於水永遠全部同步保留。

## 來源差異

- 講義將 metyrapone 稱唯一可用於孕婦的抑制藥及美國無售。 此為教材時點／過度絕對敘述；複習只記機轉與例子，不當目前可用性或孕婦醫療建議。（類固醇講義 PDF p.26；Ch39）
- 講義稱 mitotane 美國未上市。 不採用可用性敘述；保留 adrenolytic 與腎上腺皮質癌用途。（類固醇講義 PDF p.27；Ch39）
- 講義把 finerenone 泛稱治高血壓與心衰。 表格保留非類固醇 MR 拮抗與高 K 風險；具體適應症依地區與年份，不以此當通用治療指示。（類固醇講義 PDF p.28；Ch39）
- 口述將 COX-2 和 leukotriene 生合成混成同一路。 COX 通往 prostanoids；leukotrienes 由 LOX，GC 較上游／多基因抗炎，不能畫 COX→LT。（1001淨化稿 L177–183；Ch39）
- 講義產前 dex 防 CAH 雄性化可能被看成常規。 標為課堂機轉例，產前處置需專科評估，與已確立的早產胎肺成熟用途分開。（類固醇講義 PDF p.20、22；Ch39）

## 回想練習

- 為何原發 Addison 常同時補 hydro 和 fludro？
  - 腎上腺本身破壞，可同時缺 GR 與 MR 荷爾蒙；續發不足常保留 aldosterone。（類固醇講義 PDF p.18、24）
- GR 拮抗與合成抑制如何區分？
  - Mifepristone 打受體；metyrapone 打 CYP11B1；前者 cortisol 不一定下降。（類固醇講義 PDF p.26–29）
- 為何長期外給 GC 後突然停藥危險？
  - HPA 負回饋抑制，自身 cortisol 供應尚未恢復。（類固醇講義 PDF p.7；淨化稿 L55–69）
- GC 抑制免疫，為何血中嗜中性球反而↑？
  - demargination／骨髓釋放／減少組織移行等；血中數量不等於抗感染功能變強。（類固醇講義 PDF p.12；淨化稿 L201–207）
- 胎肺成熟選 dex／beta 的原因？
  - 能較有效通過胎盤，不易被胎盤 11β-HSD2 失活；低 MR 活性。（類固醇講義 PDF p.22–24；淨化稿 L415–447）
- 11β-HSD2 的功能與 metyrapone 相同嗎？
  - 不同：HSD2 把 cortisol→cortisone；metyrapone 阻斷合成中的11β-hydroxylase。（類固醇講義 PDF p.9、25）
- GC 促脂解，為何長期又中心型肥胖？
  - 組織差異、食慾、insulin／脂質代謝與重分布的淨效應，不能只沿單一脂解箭頭推外觀。（類固醇講義 PDF p.10；Ch39）
- Spironolactone／eplerenone 都可能有哪個電解質毒性？
  - 高血鉀；阻 MR 使排鉀作用減少。（類固醇講義 PDF p.28）
